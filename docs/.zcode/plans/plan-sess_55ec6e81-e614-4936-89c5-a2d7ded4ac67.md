# Linkbase 文档彻底更新:编辑器换 Tiptap + 功能对齐 docmost

## 一、已确认的决策(本次变更基调)

1. **编辑器**:BlockSuite(vendor 0.22.4)→ **Tiptap v3(ProseMirror 6)+ @tiptap/react**,自研扩展包,不 vendor、无版本特例。
2. **功能基线**:对齐 **docmost 开源版基本功能**(编辑器能力、页面管理、搜索、回收站、历史、评论、导入导出等),仅对齐功能与交互形态,**不搬其技术栈**(后端保持 Hono on Bun + Drizzle + PostgreSQL 18,前端保持 React + shadcn/ui + Tailwind 4)。
3. **概念模型**:**不引入 Space**,保持 Workspace → Page(页面无限嵌套);Base(数据库)保留为模型中的一种页面内容形态,实现从 P0 降级到 P1(Tiptap 下需完全自研表格/看板,docmost 开源版亦无此功能)。
4. **清理**:删除 `archive/`(34 篇)与 `memory/`(9 篇),历史沿革只保留在 91 变更记录;根目录 16 篇中所有旧方案残留(BlockSuite vendor 方案、「与旧模型决裂」对照表、Edgeless、历史教训注记)全部清除。`.pi/` 为今日调研缓存,保留不动。
5. **文件重命名**:`02-核心模型-万物基于Block.md` → `02-核心模型-工作区与页面.md`;`05-BlockSuite集成设计.md` → `05-编辑器集成设计.md`(全部交叉引用同步更新)。
