## 1.1 本轮实施摘要（2026-10-06 新环境复验会话，Linux/WSL，环境搭建 + 运行修复）

- **环境搭建**：无 Docker → 直接 apt 原生 PostgreSQL 17 + Redis 8（`requirepass hello`）；`.env` 的 `REDIS_URL` 改 `redis://:hello@localhost:6379` 带密码形式；`db:migrate`（12 表 + pg_trgm）与 `db:seed`（dev@linkbase.local）成功；`compose.dev.yml` 保留给有 Docker 的环境；
- **typecheck 修复（TS 7.0.2 / hono 4.13.13 / drizzle 0.45.3 事实校准）**：web tsconfig 移除 `baseUrl`（TS7 已删）+ paths 加 `./` 前缀；ydoc tsconfig 补 `types:["bun"]`；`createApp` 改 `Hono<AppEnv>`、`mountStatic` 参数随改；auth JWT payload 经 `unknown` 二段 cast；`createMiddleware<AppEnv>` 不绑路径泛型时 `c.req.param()` 返回 `string | undefined`（挂载点均含 `:wsId` 字面量，workspace.ts 加 `!` 断言）；**drizzle 0.45 update/delete 不带 `.returning()` 的 awaited 结果类型为 never**（pages/tags patch 改 `.returning({id})` 判空）；RedisLike 补 `with(url)`、globalThis cast 走 unknown；
- **测试修复（含两个从未跑过的潜伏缺陷）**：①server 测试动态 import 相对路径错一级（`../src/` → `../../src/`，test/api/ 下原路径指向不存在的 test/src/，此前类型检查未跑故未暴露）；②测试注册触发限流 429 → 测试头部放宽 `RATE_LIMIT_*`（env 在动态 import app.ts 时才求值，设置先生效）；③回收站用例按扁平数组断言子页，而接口返回嵌套树 → 递归查找（DB 行状态实证正确，纯测试缺陷）；④**标签重名 500→409：Bun 的 PostgresError 把 SQLSTATE 放在 `errno`（`code` 是 `ERR_POSTGRES_SERVER_ERROR`）**，原 `includes('unique')` 与 auth.service 的 `.code==='23505'` 判断全部失效——抽 `lib/pg-errors.ts` `isUniqueViolation`（walk cause 链 + errno/code 双查）供 tags/auth 共用（注册并发 409 此前同样靠前置查重掩盖）；⑤搜索 trigram `%` 是相似度阈值匹配，短查询 vs 长文本几乎必低于 0.3 → 改 ILIKE 子串（gin_trgm_ops 同样可加速）；
- **前端修复**：`api-types.ts` 重建为 contracts/types 聚合导出（原文件疑似 EDR 损坏只剩 InviteInfo）；api.ts 调用面 `body: JSON.stringify(x)` → `json: x`（RequestOptions 契约，9 处）；editor-page 面包屑 `new Map()` 缺键值对映射（真 bug，编译期暴露）；QueryClient 移除 gcTime（默认即 5min）；登录页 Vitest 断言对齐新 UI（品牌字+副标题，`login.title` 不再渲染）；路由错误兜底接入 i18next 单例（common 新增 pageError/reload）；check-i18n 硬编码扫描排除 `*.test.tsx`（测试断言本就是被翻译文案本身）；
- **运行时修复**：**Bun `redis.send()` 第二参数必须为数组**，缺省抛 "Arguments must be an array" → wrapRedis 的 ping 永假、health 恒报 `redis:false`（KV 读写本身正常，仅探活误报）；修复后 health 全绿 `{ok,db:true,redis:true}`；
- **验收状态**：`bun run check` 全绿；M0 API 冒烟通过（注册 201 带 welcomePageId 零仪式 → 快速开始页 doc 1800B → 树/建子页/改标题/refresh 旋转全通）；图形化浏览器验收因本环境无浏览器后端未跑（Windows 机 §5 补充 9 已实证首屏）。
